# Demonstração do agente — 3 turnos

## Turno 1

**Cliente:** Hi, my order hasn't arrived yet, where is it?

**Agente:** I understand you’re asking about the status of your order. Could you please provide your order number so I can check the shipping details for you?

## Turno 2

**Cliente:** Actually this product arrived damaged, I want my money back.

**Agente:** I’m sorry to hear the product arrived damaged and you’d like a refund. Could you share your order number and, if possible, a photo of the damaged item so we can process the return and refund?

## Turno 3

**Cliente:** yes that's right

**Agente:** Great, thank you. Please provide your order number (and a photo of the damaged item if you can) so we can start the refund process.
